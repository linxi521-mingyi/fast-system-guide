FAST数字孪生及智慧维护系统

本系统面向 FAST 主动反射面与馈源支撑的运行监测与运维保障， 将三维展示与九大功能统一到同一门户：日常掌握温度、索力与断丝状态， 异常时可查阅告警，并为诊断评估、备件保障与信息发布预留完整界面。

系统概要 · 三点说明

1

已具备的核心能力

统一登录与门户、温度场 / 索力 / 断丝三维监测大屏，以及告警记录与导出。监测结果可叠加于三维模型，便于直观研判。

2

已铺设的运维链条

故障诊断、寿命预测、健康评估、备品备件、运行日志、信息发布等模块界面与交互已按运维流程完成布局，便于后续接入真实业务结果。

3

下一阶段的关键需求

需要诊断、寿命、健康等模型按统一标准输出结果，并明确测点编码、告警等级等基础规范，以便多方协同对接。

九大功能简述

每个模块说明其用途，并标注当前数据成熟度。

真实数据

运行状态监测

用于日常掌握反射面温度分布与索力状态，支持曲线对照、历史回看及数据下载，是系统当前最完整的监测能力。

对应页面：温度场监测、索力监测及对比 / 下载相关页

演示数据

故障诊断结果

以清单形式呈现诊断对象、类型、等级、置信度与处理建议，并可在三维模型上定位。界面形态已定，正式结论待诊断模型接入。

演示数据

寿命预测结果

展示主索、钢丝绳、促动器等关键资产的剩余寿命、风险等级与变化趋势，为检修安排提供依据。正式数据待寿命模型接入。

演示数据

健康状态评估

给出综合健康指数，并按子系统分别评分，便于阶段性汇报与问题定位。当前评分为界面示意。

演示数据

备品备件管理

支持备件台账、安全库存提示及出入库登记，形成运维物资管理入口。当前为演示台账，待对接业务库存系统。

统一入口

系统显示平台

作为温度场、索力、断丝三块监测大屏的统一入口，便于快速切换不同云图视图。

真实数据

故障警报展示

按状态对索段着色（正常 / 疑似 / 高度疑似 / 干扰），告警明细可与模型对照，并支持下载留存，已接入真实告警流水。

演示数据

运行日志生成

汇集系统与人员相关事件，支持生成运行日报摘要，便于交接班与归档。事件源待与真实操作及告警汇聚对接。

演示数据

信息发布

在系统内编辑维护计划与通知通报并完成发布演示，实际推送通道待接入正式业务系统。

建议介绍路径

约八至十二分钟的演示顺序，便于条理清晰。

  1. 登录与门户——展示统一入口与九大功能总览
  2. 温度场监测——三维云图、曲线面板与按日查询 / 回放
  3. 索力监测——索段着色与极值排列对照
  4. 断丝预警与告警记录——状态色标、列表联动与导出能力
  5. 诊断 / 寿命 / 健康——说明界面与交互设计，并注明当前为演示数据
  6. 备件 / 日志 / 发布——说明运维保障环节的产品形态与后续对接方向

后续数据与协作重点

监测数据持续完善

  • 统一温度、索力测点目录与编码
  • 规范告警类型与等级定义
  • 三维模型与测点坐标版本化管理

研判与运维结果接入

  • 诊断结论及其三维定位信息
  • 寿命预测与健康评估结果
  • 备件流水、运行事件与发布回执

数字孪生深化（中长期）

  • 促动器油压与活塞伸出量等边界条件
  • 馈源舱位置坐标
  • 有限元计算得到的力、应力与位移云图

  3. 随后 将备件、日志、发布接入真实业务系统
  4. 中长期 推进有限元 / 孪生求解服务在线化

  3. 后续需在模型输出格式、测点编码与告警等级等标准上进一步协同完善。
