特色功能是怎么做出来的

分两层理解：底层把信号「看明白」，上层把结果「画到天眼三维上」。下面用通俗说法说明关键环节。

① 采集温度、索力、振动等传感器持续上报
→
② 分析傅里叶 / 特征提取 / 智能识别
→
③ 入库结果写入监测与特征库
→
④ 展示本系统三维着色、曲线与告警
监测云图

温度场 / 索力 · 三维着色怎么来的

传感器先把各测点温度、索力采进来，存进数据库。网页打开时，服务端取出同一时刻（或回放时刻）的一串数值，前端按色标涂到反射面三维模型上——偏热偏红、索力偏大也偏红，相当于「把表格变成一张会说话的地图」。

旁边的折线、柱状图，是同一批数据按时间或测点排开，方便对照趋势。

信号处理

傅里叶变换 · 从「一团振动」里拆出频率成分

断丝、异常冲击往往藏在振动信号里。时域波形像一团上下跳动的线，人眼很难直接判断。傅里叶变换（含 FFT 快速算法）把信号拆成不同频率的强弱分布——类似把混在一起的声音，分成低音、中音、高音分别看。库中已有振动频谱等特征数据表，为后续判别提供「听得见的频谱画像」。

还可结合基频、波长等相关特征，观察索力变化与结构振动是否异常。

智能识别

CNN 等模型 · 自动辨认「像不像断丝」

卷积神经网络（CNN）擅长从图像或频谱图里自动抓取模式：先用大量正常 / 疑似 / 高度疑似样本学习，再对现场新来的频谱或时频特征做分类。通俗理解：不是靠人工一条条盯波形，而是让模型学会「断丝长什么样」，给出等级与置信度，再推送到告警与诊断界面。

本平台侧重展示与追溯；模型训练与推理在分析侧完成，结果经接口进入三维色标与告警列表。

断丝预警

从特征到「绿黄红蓝」四色状态

分析侧综合频谱特征与识别结果，形成告警流水（时间、测点、传感器、类型、次数等）。展示页按约定着色：绿正常、黄疑似、红高度疑似、蓝干扰；点列表即可对照模型上的索段位置，实现「结论—位置」一体查看。

数字孪生

有限元与边界条件 · 让模型「算得动」

更深层的孪生能力：把促动器油压、活塞伸出量、温度场、馈源舱位置等实测值作为边界条件，送入有限元数值模型，计算索力、应力、变形，再以颜色段叠回三维场景。展示系统已具备承载这些云图的能力；在线求解服务可按科研进度逐步接入。

界面承接

诊断 / 寿命 / 健康 · 结果怎么上屏

这几类页面采用「左侧结论清单 + 中间三维定位」的结构。分析模型输出对象、类型、等级、置信度、建议或剩余寿命后，前端负责列表展示与模型高亮。当前可用演示数据走通交互；正式结论替换为模型接口返回即可。

介绍时可用的一句收束： 傅里叶解决「信号里有什么频率」，CNN 等模型解决「这些模式像不像故障」，三维平台解决「结果出现在结构的哪一段」——采集、分析、展示形成闭环。
